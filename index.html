Agent Town
My AI agents, as a town

Agent Town is a 3D town in the browser where each of my AI agents is a character with a home and an office. It is a visual skin over a system that was already running: a job queue, local models on one GPU, and Claude. Every walk, light and animation comes from a real job, model server or file, so I can see who is working on what across my projects without reading logs.

02 / What it does

An operations console that looks like a game

See who is working

Each agent shows exactly one state — working, queued, waiting on me, blocked, offline, paused, sleeping or idle — decided by one tested rule from its real jobs. A server that does not answer is shown as offline, never as asleep.

What needs me

Approvals, blocked agents, security alerts and new finds sit in one list, ranked by how much queued work each answer would unblock, with the calculation on the card.

Talk to any agent

Chat with any agent on a local model or Claude, gather several in a board room, or ask the café DJ for a record. Every conversation is kept.

Act safely

Run now, pause, resume and assign show a preview first and need a confirm. Every action goes through the job queue’s own lock; the town never runs work itself and never touches a running job.

Keep the record

A Done log keeps every finished job for good, with who did it and what it produced. The town’s own Overseer checks every agent each hour and raises a flag rather than fixing anything itself.

Honest numbers

Money counts only when verified with evidence; a project with no entries says “no revenue recorded yet”, not $0. No revenue, time saved or adoption is claimed.
